# ClickHouse MCP

Queries a ClickHouse analytics cluster. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/mcp-clickhouse

Installs from the Camillia hub as `clickhouse-mcp-d647d4`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
